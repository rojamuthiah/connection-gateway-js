# Relay Tree (JavaScript)

This app is kept separate from the `connection-gateway` benchmark.

## Run

From this directory, install dependencies and start the server:

```sh
npm install
npm start
```

The server listens on port `8080` by default. Copy `.env.example` to `.env` to
configure the port with `PORT`. The Postman collection in this directory
contains requests for the relay-tree API.
